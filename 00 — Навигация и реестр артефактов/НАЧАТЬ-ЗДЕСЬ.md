# Начать здесь

Проектный хаб предназначен для всех участников проекта «Голос рода». Технические знания для работы с материалами не требуются.

## Где что находится

| Раздел | Содержание |
|---|---|
| `01 — Концепция и требования` | Цель проекта и описание того, каким должен быть продукт |
| `02 — Карта сайта и пользовательские сценарии` | Страницы сайта и действия пользователей |
| `03 — Дизайн и прототипы` | Визуальные решения, референсы и макеты |
| `04 — Разработка и техническая документация` | Информация для подрядчиков и разработчиков |
| `05 — Тестирование и обратная связь` | Задания для проверки сайта и найденные проблемы |
| `06 — Решения и протоколы встреч` | Принятые решения и итоги встреч |
| `07 — Бэклог и статус задач` | Все задачи, приоритеты и ответственные |
| `08 — Материалы проекта` | Презентации, ссылки, изображения и документы |
| `99 — Архив` | Устаревшие материалы |

## Как добавить материал

1. Выберите подходящий раздел.
2. Назовите файл так, чтобы его назначение было понятно без открытия.
3. Укажите автора и дату внутри документа.
4. Добавьте документ в реестр артефактов.
5. Сообщите координатору проекта о добавлении.
