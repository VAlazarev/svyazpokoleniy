# Пользовательские сценарии

## Новый пользователь

```text
Главная → Регистрация → Создание семейного пространства → Родовое дерево → Добавление первого человека
```

## Добавление родственника

```text
Родовое дерево → Добавить человека → Указать данные → Выбрать родственную связь → Сохранить
```

## Добавление материала

```text
Карточка человека → Добавить материал → Выбрать файл или воспоминание → Проверить данные → Сохранить
```

## Приглашение родственника

```text
Участники → Пригласить → Указать контакт → Выбрать права → Отправить приглашение
```

## Проверка и исправление данных

```text
Карточка человека → Изменить → Исправить данные → Сохранить → Запись об изменении
```
