# Предложения по использованию искусственного интеллекта

## Возможные функции

- Распознавание текста на фотографиях документов.
- Расшифровка аудиовоспоминаний.
- Создание черновика биографии на основе подтверждённых материалов.
- Поиск имён, дат и мест в семейном архиве.
- Предложение связи материала с человеком в дереве.
- Поиск возможных противоречий в датах и родственных связях.

## Обязательные правила

- Результат ИИ всегда является черновиком.
- Пользователь подтверждает сведения перед сохранением.
- Исходный файл сохраняется рядом с распознанными данными.
- Система показывает, какие данные были предложены ИИ.
- Семейные материалы нельзя использовать для обучения внешних моделей без отдельного согласия.
