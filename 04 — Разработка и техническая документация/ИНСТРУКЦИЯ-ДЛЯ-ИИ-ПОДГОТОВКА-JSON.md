# Скрипт для DeepSeek: фотография дерева в JSON

Пользователь передаёт этот текст DeepSeek вместе с фотографией существующего семейного дерева и примером JSON.

## Текст скрипта

```text
К сообщению прикреплена фотография семейного дерева и пример JSON для сайта «Голос рода».

Распознай людей, даты и родственные связи на фотографии. Верни результат в структуре приложенного примера JSON.

Правила:
1. Не придумывай сведения, которых нет на фотографии.
2. Если значение неизвестно или не читается, укажи null.
3. Создай для каждого человека уникальный идентификатор: p1, p2, p3 и далее.
4. Отдельно запиши фамилию, имя и отчество.
5. Полную дату записывай в формате ГГГГ-ММ-ДД.
6. Если известен только год, запиши год и укажи точность year.
7. Для приблизительной даты используй точность about.
8. Родственные связи записывай через идентификаторы людей.
9. Не создавай родственную связь, если её нельзя определить по фотографии.
10. Для сомнительных значений установи needs_review: true.
11. Укажи уверенность распознавания числом от 0 до 1.
12. Все сомнения и противоречия добавь в warnings.
13. Верни только корректный JSON без пояснений до и после него.
```

## Действия пользователя

1. Открыть DeepSeek.
2. Прикрепить фотографию семейного дерева.
3. Прикрепить файл `ПРИМЕР-ИМПОРТА-СЕМЕЙНОГО-ДЕРЕВА.json`.
4. Вставить текст скрипта.
5. Отправить запрос.
6. Скопировать полученный JSON.
7. Сохранить его в файл с расширением `.json`.
8. Открыть на сайте «Голос рода» загрузку дерева из JSON.
9. Загрузить файл.
10. Просмотреть предварительное дерево.
11. Исправить ошибки.
12. Подтвердить импорт.

## Важно

Результат DeepSeek является черновиком. Пользователь проверяет все имена, даты и связи до загрузки дерева на сайт.
