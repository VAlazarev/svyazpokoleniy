# Инструкция для ИИ по подготовке семейного дерева к импорту

Эту инструкцию пользователь передаёт ИИ вместе с фотографиями, PDF, снимками экрана или текстовым описанием семейного дерева.

## Текст инструкции

```text
Тебе переданы материалы о семейном дереве: фотографии, сканы, PDF, снимки экрана или текст.

Подготовь данные для импорта в проект «Голос рода».

Правила:
1. Не придумывай отсутствующие сведения.
2. Если значение неизвестно, укажи null.
3. Создай для каждого человека уникальный идентификатор: p1, p2, p3 и так далее.
4. Отдельно запиши фамилию, имя и отчество.
5. Даты записывай в формате ГГГГ-ММ-ДД. Если известен только год, запиши год и укажи точность year.
6. Для приблизительной даты используй точность about.
7. Для каждой родственной связи используй идентификаторы людей.
8. Не создавай связь, если она не указана или не видна в источнике.
9. Для каждого распознанного человека и связи укажи источник: название файла, страницу или описание фрагмента.
10. Укажи уверенность числом от 0 до 1.
11. Все сомнения и противоречия добавь в warnings.
12. Верни только корректный JSON без пояснений до и после него.

Используй структуру из приложенного файла «ПРИМЕР-ИМПОРТА-СЕМЕЙНОГО-ДЕРЕВА.json».
```

## Действия пользователя

1. Скачать эту инструкцию и пример JSON.
2. Открыть доступный ИИ-сервис, который умеет работать с файлами и изображениями.
3. Прикрепить фотографии, PDF, снимки экрана или текст.
4. Прикрепить пример JSON.
5. Вставить текст инструкции.
6. Получить результат.
7. Сохранить результат в файл с расширением `.json`.
8. Загрузить файл на страницу импорта «Голос рода».
9. Проверить найденных людей, даты и связи.
10. Исправить ошибки и только после этого подтвердить импорт.

## Важно

- Пользователь должен передавать только те семейные материалы, которые имеет право обрабатывать.
- Нельзя отправлять внешнему ИИ паспортные данные и другие чувствительные документы без необходимости и отдельного понимания условий сервиса.
- Результат ИИ является черновиком и не должен импортироваться без проверки человеком.
