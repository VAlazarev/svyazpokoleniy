# Скрипт для DeepSeek: фотография дерева в JSON

Пользователь передаёт этот текст DeepSeek вместе с фотографией существующего семейного дерева. Требуемая структура JSON уже включена в скрипт.

## Текст скрипта

```text
К сообщению прикреплена фотография семейного дерева.

Распознай людей, даты и родственные связи на фотографии. Верни результат в следующей структуре:

{
  "format_version": "1.0",
  "source": {
    "type": "image",
    "name": "название прикреплённой фотографии",
    "description": "Фотография семейного дерева"
  },
  "people": [
    {
      "id": "p1",
      "last_name": null,
      "first_name": null,
      "middle_name": null,
      "gender": null,
      "birth": {
        "date": null,
        "precision": null,
        "place": null
      },
      "death": null,
      "notes": null,
      "source_refs": [],
      "confidence": 0,
      "needs_review": true
    }
  ],
  "relationships": [
    {
      "id": "r1",
      "type": "parent_child",
      "parent_id": "p1",
      "child_id": "p2",
      "source_refs": [],
      "confidence": 0,
      "needs_review": true
    }
  ],
  "warnings": []
}

Правила:
1. Не придумывай сведения, которых нет на фотографии.
2. Если значение неизвестно или не читается, укажи null.
3. Создай для каждого человека уникальный идентификатор: p1, p2, p3 и далее.
4. Отдельно запиши фамилию, имя и отчество.
5. Полную дату записывай в формате ГГГГ-ММ-ДД.
6. Если известен только год, запиши год и укажи точность year.
7. Для приблизительной даты используй точность about.
8. Родственные связи записывай через идентификаторы людей.
9. Не создавай родственную связь, если её нельзя определить по фотографии.
10. Для сомнительных значений установи needs_review: true.
11. Укажи уверенность распознавания числом от 0 до 1.
12. Все сомнения и противоречия добавь в warnings.
13. Верни только корректный JSON без пояснений до и после него.
```

## Действия пользователя

1. На сайте «Голос рода» нажать «Загрузить данные».
2. Нажать «Получить скрипт».
3. Нажать «Скопировать скрипт».
4. Открыть DeepSeek.
5. Вставить скопированный текст.
6. Прикрепить фотографию семейного дерева.
7. Отправить запрос.
8. Скопировать полученный JSON.
9. Вернуться на сайт «Голос рода».
10. Вставить JSON в поле «Результат DeepSeek» или сохранить его в файл `.json` и загрузить этот файл.
11. Нажать «Проверить данные».
12. Просмотреть предварительное дерево.
13. Исправить ошибки.
14. Подтвердить импорт.

## Важно

Результат DeepSeek является черновиком. Пользователь проверяет все имена, даты и связи до загрузки дерева на сайт.
