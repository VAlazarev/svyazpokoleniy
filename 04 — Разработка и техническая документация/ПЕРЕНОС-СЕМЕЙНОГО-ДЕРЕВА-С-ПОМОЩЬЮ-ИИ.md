# Перенос семейного дерева из фотографии через DeepSeek

## Предлагаемый вариант реализации

Использовать подготовленный скрипт для DeepSeek, который преобразует фотографию существующего семейного дерева в JSON.

Пользователь начинает работу на сайте «Голос рода», получает готовый скрипт для DeepSeek, обрабатывает фотографию и возвращает полученный JSON на сайт. Результат можно вставить в поле или загрузить файлом.

Другие варианты использования искусственного интеллекта в рамках этого предложения не рассматриваются.

## Пользовательский сценарий

1. Пользователь входит на сайт «Голос рода».
2. Нажимает кнопку «Загрузить данные».
3. Сайт открывает инструкцию по переносу дерева из фотографии.
4. Пользователь нажимает «Получить скрипт».
5. Сайт показывает подготовленный текст для DeepSeek.
6. Пользователь нажимает «Скопировать скрипт».
7. Открывает DeepSeek.
8. Вставляет скопированный скрипт.
9. Прикрепляет фотографию своего семейного дерева.
10. DeepSeek распознаёт людей, даты и родственные связи.
11. DeepSeek возвращает JSON установленного формата.
12. Пользователь возвращается на сайт «Голос рода».
13. Вставляет JSON в поле «Результат DeepSeek» или загружает файл `.json`.
14. Нажимает «Проверить данные».
15. Сайт проверяет структуру JSON.
16. Сайт показывает предварительный вид дерева.
17. Пользователь просматривает и исправляет людей, даты и связи.
18. Пользователь подтверждает импорт.
19. Сайт создаёт родовое дерево.

## Состав JSON

JSON содержит:

- версию формата;
- сведения об исходной фотографии;
- список людей;
- фамилию, имя и отчество каждого человека;
- даты и места рождения и смерти;
- родственные связи между людьми;
- отметки о сомнительно распознанных сведениях;
- предупреждения, требующие проверки пользователя.

## Ограничения

- DeepSeek формирует только черновик данных.
- Сайт не сохраняет дерево без подтверждения пользователя.
- DeepSeek не должен придумывать отсутствующие имена, даты и связи.
- Неизвестные значения передаются как `null`.
- Пользователь загружает только те семейные материалы, которые имеет право обрабатывать.
- Перед использованием DeepSeek пользователь должен учитывать условия обработки данных этого сервиса.
