# Перенос семейного дерева из фотографии через DeepSeek

## Предлагаемый вариант реализации

Использовать подготовленный скрипт для DeepSeek, который преобразует фотографию существующего семейного дерева в JSON.

Пользователь получает JSON от DeepSeek и загружает его на сайт «Голос рода». Сайт создаёт из файла черновик родового дерева.

Другие варианты использования искусственного интеллекта в рамках этого предложения не рассматриваются.

## Пользовательский сценарий

1. Пользователь открывает подготовленный скрипт в DeepSeek.
2. Прикрепляет фотографию своего семейного дерева.
3. DeepSeek распознаёт людей, даты и родственные связи.
4. DeepSeek формирует JSON установленного формата.
5. Пользователь сохраняет полученный файл с расширением `.json`.
6. Пользователь входит на сайт «Голос рода».
7. Открывает раздел импорта семейного дерева.
8. Загружает полученный JSON.
9. Сайт проверяет структуру файла.
10. Сайт показывает предварительный вид дерева.
11. Пользователь просматривает людей, даты и родственные связи.
12. Пользователь исправляет ошибки при необходимости.
13. Пользователь подтверждает импорт.
14. Сайт создаёт родовое дерево.

## Что уже подготовлено

- Скрипт для DeepSeek: `ИНСТРУКЦИЯ-ДЛЯ-ИИ-ПОДГОТОВКА-JSON.md`.
- Пример формата: `ПРИМЕР-ИМПОРТА-СЕМЕЙНОГО-ДЕРЕВА.json`.

## Что нужно реализовать на сайте

1. Кнопку «Загрузить дерево из JSON».
2. Форму выбора файла `.json`.
3. Проверку структуры и обязательных полей файла.
4. Понятное сообщение, если файл сформирован неправильно.
5. Предварительный список найденных людей.
6. Предварительный вид родового дерева.
7. Возможность исправить имена, даты и связи до сохранения.
8. Подтверждение окончательного импорта.
9. Защиту от создания одинаковых людей при повторной загрузке.

## Состав JSON

JSON содержит:

- версию формата;
- сведения об исходной фотографии;
- список людей;
- фамилию, имя и отчество каждого человека;
- даты и места рождения и смерти;
- родственные связи между людьми;
- отметки о сомнительно распознанных сведениях;
- предупреждения, требующие проверки пользователя.

## Ограничения

- DeepSeek формирует только черновик данных.
- Сайт не сохраняет дерево без подтверждения пользователя.
- DeepSeek не должен придумывать отсутствующие имена, даты и связи.
- Неизвестные значения передаются как `null`.
- Пользователь загружает только те семейные материалы, которые имеет право обрабатывать.
- Перед использованием DeepSeek пользователь должен учитывать условия обработки данных этого сервиса.
