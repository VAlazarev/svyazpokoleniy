# Проектный хаб «Голос рода»

Единое пространство для документов, решений, макетов, задач, тестирования и материалов проекта.

## Структура

```text
Проектный хаб
├── 00 — Навигация и реестр артефактов
├── 01 — Концепция и требования
├── 02 — Карта сайта и пользовательские сценарии
├── 03 — Дизайн и прототипы
├── 04 — Разработка и техническая документация
├── 05 — Тестирование и обратная связь
├── 06 — Решения и протоколы встреч
├── 07 — Бэклог и статус задач
├── 08 — Материалы проекта
└── 99 — Архив
```

## С чего начать

1. Откройте папку `00 — Навигация и реестр артефактов`.
2. Прочитайте файл `НАЧАТЬ-ЗДЕСЬ.md`.
3. Найдите нужный материал в реестре артефактов.
4. Для проверки сайта перейдите в раздел `05 — Тестирование и обратная связь`.
5. Новые задачи и предложения добавляйте в раздел `07 — Бэклог и статус задач`.

## Общие правила

- Все названия и документы создаются на русском языке.
- Не загружайте пароли, ключи, банковские сведения и копии документов.
- Персональные данные размещаются только в защищённом хранилище с ограниченным доступом.
- Тяжёлые фото, видео и макеты хранятся на общем Google Диске; в хабе размещаются ссылки.
- У каждого значимого документа должны быть владелец, статус и дата обновления.
