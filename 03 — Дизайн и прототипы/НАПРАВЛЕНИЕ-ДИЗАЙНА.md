# Направление дизайна

## Общий стиль

- Тёмно-зелёный фон.
- Тёплые золотые акценты.
- Образ дерева, корней и семейного наследия.
- Светлые карточки людей с хорошей читаемостью.

## Важные ограничения

- Не использовать чрезмерное свечение вокруг текста.
- Не перегружать экран декоративными деталями.
- Ясно показывать родственные связи.
- Главные кнопки должны быть заметны без подсказок.
- Интерфейс должен оставаться удобным на телефоне.
- Референсы с названием «Легенда» используются только как визуальное направление; бренд продукта — «Голос рода».
